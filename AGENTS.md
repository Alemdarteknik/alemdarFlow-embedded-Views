# Repository Instructions

## Visual bug fixes

- Inspect every supplied screenshot at original resolution.
- Read the affected component and its surrounding layout before editing.
- Identify and state the concrete root cause before changing code.
- Make the smallest scoped change that fixes that cause while preserving existing styling and behavior.
- Treat small UI bugs as implementation work and proceed without broad design questions.
- Verify the result at the same viewport size before reporting completion.
- Completion requires the supplied visual defect to be absent, relevant checks to pass, and unrelated UI to remain unchanged.
